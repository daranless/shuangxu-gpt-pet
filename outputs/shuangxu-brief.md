# 霜序：白发浅紫龙娘研究搭档

用户提供的白发龙娘图片是身份参考。保留白发、淡紫眼睛、弯曲龙角、蝠翼、龙尾与白紫礼服；为小尺寸动画采用紧凑动漫比例和清晰轮廓。名字由本次创作选择。机器人主题的小齿轮胸针是设计意图，需以最终图像是否实际出现为准。

个性设定：安静、认真，陪伴机器人控制研究、代码调试与论文写作。

图中悬浮小球不进入精灵，以保持主体连通。所有新视觉使用内置 imagegen；动画拆分、组装和检查使用 Pets 技能附带脚本。

当前设定不包含语音、GPT 对话接口或 Live2D 骨骼。Pets 精灵与可对话的虚拟人框架是不同交付物。

## GitHub 调查（2026-10-11）

- [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber)：Live2D、语音交互、OpenAI 兼容接口，中文 README 明确列出透明置顶、鼠标穿透的桌面宠物模式。适合参考图的二维形象方向。
- [AIRI](https://github.com/moeru-ai/airi)：AI 角色伴侣，提供网页与桌面版本，支持 Live2D/VRM，README 列出 OpenAI 等模型接口。适合进一步研究角色行为与桌面伴侣扩展。
- [Amica](https://github.com/semperai/amica)：可导入 VRM 的三维角色对话界面，支持 ChatGPT API、语音识别和语音合成。
- [ChatVRM](https://github.com/pixiv/ChatVRM)：VRM + ChatGPT API 的演示项目，仓库已归档，适合学习实现，不优先用于新部署。

这些项目提供角色运行框架；这张 PNG 参考图本身还不是可加载的 Live2D 或 VRM 模型。角色模型及美术资产许可需独立查看。

## 制作结果

已生成九类动作与十六个视线方向，共 73 帧，1536×2288 透明 PNG。逐帧、最终精灵表、质量门、三人独立方向复核和 Pets MCP 上传前验证均通过。方向复核中的少量中间角度单轴歧义保留为警告，四个基本方向一致通过。跳跃相对待机基线最高抬升 41 像素，落地差 1 像素。完整动作 GIF、MP4、待机—跳跃—待机预览、视线循环、接触表和质量报告均已保存。

本仓库分发角色素材与离线预览。应用内的创建、选用和持久身份属于各自账号，不随仓库下载而安装。历史状态快照仅记录制作时状态。
